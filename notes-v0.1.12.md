## r0 v0.1.12

### New Features
- Added new editor command palette shortcuts
- Added support for custom color themes
- Added terminal panel improvements
- Added language-aware local completions for JavaScript/TypeScript, Python, Rust, HTML, CSS, and JSON
- Added persistent Editor → Suggestions controls for automatic/manual completions, language filtering, semantic IntelliSense, and suggestion limits
- Added terminal Ctrl+C copy-versus-interrupt behavior, clipboard paste shortcuts, and a right-click Copy/Paste menu
- Added independent controls for AI inline completion, ghost text visibility, and Tab acceptance

### Bug Fixes
- Fixed crash when opening large files
- Fixed incorrect cursor position after undo

### Improvements
- Faster startup time
- Reduced memory usage when opening multiple tabs
